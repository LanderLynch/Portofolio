August 9, 2026

Full performance audit & optimization pass across the entire portfolio.

Archive

Inline JS Extraction

  • Extracted ~870 lines of inline JS from index.html into performance-main.js
  • Reduced HTML file size by ~40% (2100 → 1275 lines)
  • Non-blocking defer attribute keeps parsing fast

Font Loading

  • Google Fonts changed from blocking <link> to async preload with onload pattern
  • Added <noscript> fallback
  • Faster FCP — font no longer blocks first paint

CSS Performance

  • content-visibility: auto extended to all major sections
  • Browser skips rendering off-screen sections entirely
  • scroll-behavior moved to JS-only (smoother control)

Service Worker

  • Bumped cache version v28 → v29
  • Added dedicated IMAGE_CACHE with cache-first strategy
  • Images from Firebase/Unsplash no longer re-downloaded every visit

Network & DNS Hints

  • Added dns-prefetch for i.pinimg.com and images.unsplash.com
  • Added preload for logo image (fetchpriority=high)
  • Faster resolution for external image domains

MutationObserver Batching

  • performance-utils.js MutationObserver now batches nodes via requestAnimationFrame
  • Eliminates per-node processing jank during dynamic content insertion

Boot Loader Redesign

  • Replaced plain pulsing box with animated spinner ring + logo + "Loading" text
  • Logo loaded via Image() constructor with onload — always visible when ready
  • Preload hint ensures logo is cached before boot loader triggers

Certification Page Fixes

  • Removed ::before gradient overlay from .folder-card — card color now matches all other cards
  • Replaced accordion max-height transition with grid-template-rows: 0fr → 1fr — no more jank when opening folders

Scroll Performance

  • Scroll handler wrapped in requestAnimationFrame throttle (eliminates layout thrashing)
  • Passive scroll listener eliminates unnecessary main-thread blocking

Changelog Upgrades

  • Redesigned changelog page with version tabs (v1, v2, v3)
  • Each version gets its own tab panel with dated entries
